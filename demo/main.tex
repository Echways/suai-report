\section{Постановка задачи}

Программа получает имя текстового файла, читает из него вещественные
числа, разделённые пробелами или переводами строк, и выводит их
количество, сумму, наименьшее и наибольшее значения, среднее
арифметическое и СКО.

К программе предъявляются требования:
\suaienum
имя файла передаётся аргументом командной строки
дробная часть числа отделяется точкой
при ошибке программа выводит её причину и завершается с ненулевым кодом

Ограничения на входные данные приведены в~\tabref{limits}. Требование
из перечисления б) следует из того, как числа читает оператор
\texttt{>>}.

%%  Таблица: ячейки через |, первая строка — шапка. Черта внутри
%%  формулы ячейку не делит.
\suaitable[limits]{Ограничения на входные данные}
Величина                 | Обозначение | Ограничение
Количество чисел в файле | $n$         | $1 \le n \le 10^{6}$
Модуль числа             | $|x_i|$     | не больше $10^{9}$
Длина имени файла        | —           | определяется ОС

Среднее арифметическое вычисляется по~\formref{mean}:
%%  Формула с пояснениями: строки «обозначение | смысл» дают «где …».
\suaieq[mean]{\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i}
\bar{x} | среднее арифметическое
n | количество чисел
x_i | число с номером $i$

СКО вычисляется по~\formref{deviation} с теми же обозначениями:
%%  Без строк под командой — формула без пояснений.
\suaieq[deviation]{s = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x})^2}}

\subsection{Средства чтения}

Для чтения из файла служит класс \texttt{std::ifstream} из заголовочного
файла \texttt{<fstream>}~[1]. Способы чтения сравниваются
в~\tabref{reading}.

%%  Ширины столбцов подбираются по тексту, длинные ячейки переносятся.
\suaitable[reading]{Способы чтения из потока \texttt{std::ifstream}}
Способ                       | Что читает     | Где останавливается
\texttt{in >> x}             | одно значение  | перед символом, который не входит в запись значения
\texttt{std::getline(in, s)} | строку целиком | после перевода строки
\texttt{in.get(c)}           | один символ    | после этого символа
\texttt{in.read(buf, n)}     | $n$ байтов     | после последнего байта

Результат чтения узнают по состоянию потока:
\suailist
\texttt{in.good()} — ошибок не было
\texttt{in.eof()} — достигнут конец файла
\texttt{in.fail()} — значение прочитать не удалось

Чтение прекращается в двух случаях.
%%  Вложенное перечисление пишется окружением: первый уровень — буквы,
%%  второй — цифры.
\begin{gostenum}
  \item Числа в файле закончились:
  \begin{gostenum}
    \item установлены оба признака, \texttt{eof} и \texttt{fail};
    \item это штатное завершение чтения.
  \end{gostenum}
  \item В файле встретилось не число:
  \begin{gostenum}
    \item установлен только признак \texttt{fail};
    \item программа сообщает об ошибке.
  \end{gostenum}
\end{gostenum}
