# suai-report

Шаблон отчёта ГУАП по ГОСТ 7.32-2017 на XeLaTeX. Титульный лист совпадает
с официальным бланком, остальное оформление ставится само, а в `main.tex`
пишется только текст.

**Нужно:** TeX Live (`xelatex`, `latexmk`, `biber`), Python 3, VS Code
с расширением LaTeX Workshop (VS Code сам предложит его установить).

## Быстрый старт

Один раз после клонирования:

```bash
make install   # guap.sty -> ~/texmf, команда guap -> ~/.local/bin
```

`guap.sty` ставится симлинком на этот репозиторий, поэтому правки шаблона
и `git pull` сразу действуют во всех отчётах. В папке отчёта остаются
только `main.tex`, `images/` и `.vscode/`.

```bash
make new DIR=../3rdcourse/1term/cloudtech/lab-4 TITLE="Настройка S3"
```

Команда создаст папку отчёта и откроет её в VS Code. В `main.tex` нажми
**Ctrl+Alt+V**, и PDF откроется справа. Дальше просто пиши: файл
сохраняется сам, PDF пересобирается за 1–2 секунды.

Данные титула (кафедра, преподаватель, дисциплина, группа, студент) берутся
из самого свежего отчёта в соседних папках, а если его нет, из
`demo/main.tex` этого репозитория. Номер работы берётся из имени папки (`lab-4` → 4),
дата ставится `today`.

Следующая лаба делается ещё проще. В папке `lab-4` выполни:

```bash
guap next            # создаст ../lab-5 с тем же титулом
```

- **Ctrl+клик** по месту в PDF переходит к строке в `.tex`, **Ctrl+Alt+J**
  делает обратный переход.
- Ошибки видны в панели **Problems** (Ctrl+Shift+M). Пока ошибка не
  исправлена, остаётся открытым последний удачный PDF.
- Служебные файлы лежат в скрытой папке `build/`, готовый `main.pdf`
  лежит рядом с `main.tex`.

## Команды

В любой папке отчёта (или с путём: `guap build ../lab-4`).

| Команда | Что делает |
| --- | --- |
| `guap build` | собрать `main.pdf` |
| `guap watch` | пересобирать при каждом сохранении |
| `guap open` | собрать и открыть PDF |
| `guap clean` | удалить `build/` и PDF |
| `guap new DIR [--title "…"]` | новый отчёт |
| `guap next [--title "…"]` | следующий отчёт рядом: `lab-3` → `lab-4` |
| `guap update` | обновить `.vscode/` в отчёте из шаблона |

## Устройство

Всё, что попадает в отчёты, лежит в `src/`. Больше править негде.

```text
src/guap.sty          оформление по ГОСТ, титульный лист, команды \guap…
src/template.tex      заготовка main.tex
src/vscode/           настройки VS Code: сборка, предпросмотр, сниппеты
demo/                 демо-отчёт со всеми возможностями
scripts/guap.py       команда guap
Makefile              make install, сборка демо, make check
.vscode -> src/vscode симлинк, чтобы в самом репозитории работало то же
.github/workflows/    CI собирает демо-отчёт и свежую заготовку
```

- `guap.sty` ставится в `~/texmf` симлинком, поэтому правка `src/guap.sty`
  или `git pull` сразу действует во всех отчётах.
- `src/vscode/` копируется в `.vscode/` отчёта при `guap new`. В старые
  отчёты новые настройки и сниппеты попадают после `guap update`.
- Сборка описана один раз, в `src/vscode/settings.json` (аргументы latexmk:
  XeLaTeX + Biber, служебное в `build/`). Её используют и VS Code, и `guap build`.
- Нужен только XeLaTeX. Overleaf и LuaLaTeX не поддерживаются.
- Все настройки оформления отчёта пишутся в преамбуле `main.tex` (см. ниже).

### Правка шаблона

```bash
make watch     # демо пересобирается при сохранении main.tex и src/guap.sty
make check     # перед коммитом: собрать демо и свежую заготовку, как в CI
```

В корне шаблона для демо есть `make`, `make open`, `make clean`, а также
`make new DIR=…` и `make install` (после переноса репозитория его нужно
повторить).

## Титульный лист

```latex
\guapsetup{
  department   = 41,
  teacher-post = Ассистент,
  teacher      = Д. С. Лисюков,
  type         = Отчет о лабораторной работе,
  number       = 1,
  title        = Знакомство с менеджером заметок Obsidian,
  course       = Облачные технологии и сервисы,
  group        = 4414,
  student      = Г. В. Моисеев,
  date         = today,
}
```

- `type` и `title` переводятся в прописные автоматически.
- Если `number` пустой, номер не печатается (курсовая, доклад).
- `date = today` подставляет дату сборки. Если дату не указать,
  останутся пустые линии, чтобы вписать от руки.
- `student = {А. А. Иванов, Б. Б. Петров}` печатает строку подписи для
  каждого студента.
- `course-label = по дисциплине:` меняет подпись над названием курса.
- `year` по умолчанию равен текущему году.

Вёрстка снята с официального бланка ГУАП (Word) и совпадает с ним
до 0,25 pt. Длинное название само сжимает отступы, и город с годом
остаются на первой странице.

## Текст отчёта

**Блочная команда читает строки под собой до пустой строки.** Каждая
строка становится пунктом, строкой таблицы или пояснением.

```latex
\guapintro                              % ВВЕДЕНИЕ с новой страницы

Цель работы — изучить Obsidian.

\guaptasks                              % «Для достижения ... задачи:» + а) б) в)
установить Obsidian
настроить синхронизацию

\section{Ход работы}

Окно программы показано на~\figref{scheme}.

\guapimg{scheme}{Главное окно Obsidian}   % images/scheme.png, метка fig:scheme

Способы сравниваются в~\tabref{sync}.

\guaptable[sync]{Способы синхронизации}   % первая строка — шапка
Способ        | Стоимость | Шифрование
Obsidian Sync | 4 \$      | да
Яндекс Диск   | бесплатно | нет

Объём оценивается по~\formref{size}:
\guapeq[size]{V = N \cdot \bar{s}}        % строки ниже — «где ...»
V | объём хранилища, КБ
N | число заметок

\begin{code}[bash, backup]{Резервное копирование}   % метка lst:backup
tar -czf vault.tar.gz ~/Vault
\end{code}

\guapconclusion                         % ЗАКЛЮЧЕНИЕ

Работа выполнена.

\guapsources                            % СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ
Obsidian Help. URL: https://help.obsidian.md (дата обращения: 12.09.2026).
Фаулер М. Архитектура корпоративных программных приложений. М.: Вильямс, 2015.
```

| Команда | Что делает |
| --- | --- |
| `\guapintro`, `\guapconclusion` | ВВЕДЕНИЕ / ЗАКЛЮЧЕНИЕ с новой страницы и в содержании |
| `\guapsection{Название}` | другой структурный элемент (по центру, прописными) |
| `\guaptasks` | вводная фраза и а), б), в). `\guaptasks[Своя фраза:]`, `\guaptasks[]` без фразы |
| `\guapenum` / `\guaplist` / `\guapnum` | перечисление а) б) / через дефис / 1) 2) |
| `\guaptable[метка]{Название}` | таблица, ячейки через `\|`, первая строка — шапка |
| `\guapimg[ширина]{файл}{Подпись}` | рисунок из `images/`, метка `fig:имя-файла` |
| `\guapeq[метка]{формула}` | формула с номером, строки `обозначение \| смысл` дают «где …» |
| `\begin{code}[язык, метка]{Подпись}` | листинг в тексте, метка `lst:метка` |
| `\guapcode[язык]{файл}{Подпись}` | листинг из файла (ищется как есть, затем в `code/`) |
| `\guapsources` | список источников, каждая строка — источник |
| `\guapapp[справочное]{Название}` | ПРИЛОЖЕНИЕ А, Б, … |
| `\figref`, `\tabref`, `\lstref`, `\formref` | «рисунке 1», «таблице 1», «листинге 1», «формуле (1)» |

Что делается само:

- В перечислениях после пунктов ставится `;`, после последнего `.`.
  Свои `;` `.` `,` в конце строки заменяются, а пункт на `?`, `!` или `:`
  остаётся как есть. Со звёздочкой (`\guaplist*`) пунктуация не трогается.
- Ширины столбцов подбираются по длине текста. Длинная таблица переносится
  с надписью «Продолжение таблицы N» и повтором шапки.
- Обозначение в «где» оборачивается в `$…$`, если `$` не написан.
- Префикс метки писать не нужно: `\figref{scheme}` найдёт `fig:scheme`.

Тонкости:

- Блок заканчивается и без пустой строки, если следующая строка
  начинается с `\section`, `\begin`, `\end` или команды `\guap…`.
- `|` внутри ячейки пиши как `\vert` (в формулах) или `\textbar`.
- Пункт списка занимает одну строку файла. Длинные строки не переноси:
  в VS Code включён перенос на экране.

## Сниппеты

Начни набирать команду, например `\guapta` или просто `guapta`, и нажми
**Tab**. Вставится готовый блок с примером данных и ссылкой на него. Tab
переходит по полям, одинаковые метки заполняются сразу в обоих местах.
Если набрать только `\`, все сниппеты ГУАП окажутся вверху списка.

| Команда | Короткий префикс | Что вставляет |
| --- | --- | --- |
| `\guapimg` | `img` / `рис` | рисунок со ссылкой на него |
| `\guaptable` | `tab` / `табл` | таблицу 2×3 со ссылкой |
| `\guaptasks` | `tasks` | задачи а), б), в) |
| `\guapenum`, `\guaplist`, `\guapnum` | `enum`, `list`, `num` | перечисление а) б) / через дефис / 1) 2) |
| `\guapeq` | `eq` | формулу со ссылкой и «где …» |
| `\begin{code}` | `lst` | листинг в тексте со ссылкой |
| `\guapcode` | `code` | листинг из файла |
| `\guapsources` | `src` | список источников (дата обращения — сегодня) |
| `\section`, `\guapapp` | `sec`, `app` / `прил` | раздел, приложение |
| `\guapintro`, `\guapconclusion` | | введение, заключение |

В `.tex` подсказку принимает только Tab, а Enter всегда переносит строку.
Слова из текста не подсказываются. Это настроено в `src/vscode/settings.json`
(секция `[latex]`), в старые отчёты настройки попадут после `guap update`.

## Настройка под методичку

Все правки пишутся в `main.tex` перед `\begin{document}`:

| Что | Строка |
| --- | --- |
| Правое поле 10 мм | `\geometry{right=10mm}` |
| Интервал ровно как «1,5» в Word | `\setstretch{1.25}` |
| Нумерация формул по разделам (1.1) | `\numberwithin{equation}{section}` |
| Заголовки без полужирного | `\renewcommand{\guapheadfont}{\normalfont\fontsize{14}{17}\selectfont}` |
| Цветные листинги | `\lstset{style=gostcolor}` |

Автосохранение в VS Code отключается удалением `files.autoSave`
из `src/vscode/settings.json` (и `guap update` в отчётах).

### Источники через biblatex

Если нужны ссылки `\cite{…}`, создай `sources.bib` и добавь в преамбулу:

```latex
\usepackage[backend=biber,style=gost-numeric,language=auto,
            autolang=other,sorting=none]{biblatex}  % sorting=nyt — по алфавиту
\addbibresource{sources.bib}
```

`\guapsources` оставь без строк (сразу за ним пустая строка), тогда
список соберётся из `sources.bib`.
