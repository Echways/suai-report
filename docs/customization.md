# Настройка под методичку

[← К оглавлению](../README.md#документация)

По умолчанию отчёт оформлен по ГОСТ 7.32-2017 — что именно выставлено,
перечислено на странице [«Что шаблон делает по ГОСТ»](gost.md). Если
методичка кафедры требует другого, нужная строка добавляется в преамбулу
`main.tex`, после `\usepackage{suai-report}`.

## Страница и текст

| Что | Строка |
| --- | --- |
| Правое поле 10 мм | `\geometry{right=10mm}` |
| Интервал как «1,5» в Word (24 pt) | `\setstretch{1.42}` |
| Основной текст 12 pt | `\documentclass[a4paper,12pt]{extarticle}` |
| Без разрывов внутри слов (`_ / .` …) | `\XeTeXinterchartokenstate=0` |

Поля задаются ключами пакета `geometry`: `left`, `right`, `top`, `bottom`.
На титульный лист они не влияют: он набирается по бланку.

## Заголовки

| Что | Строка |
| --- | --- |
| Заголовки без полужирного | `\renewcommand{\suaiheadfont}{\normalfont\fontsize{14}{17}\selectfont}` |
| Раздел не с новой страницы | `\renewcommand{\sectionbreak}{}` |

`\suaiheadfont` — шрифт всех заголовков: разделов, структурных элементов,
содержания и приложений.

## Нумерация

| Что | Строка |
| --- | --- |
| Формулы по разделам: (1.1) | `\numberwithin{equation}{section}` |
| Рисунки по разделам: 1.1 | `\numberwithin{figure}{section}` |
| Таблицы по разделам: 1.1 | `\numberwithin{table}{section}` |

## Подписи

| Что | Строка |
| --- | --- |
| Короткое тире в подписях: «Рисунок 1 – …» | `\captionsetup{labelsep=endash}` |

Остальное меняется ключами пакета `caption`.

## Листинги

| Что | Строка |
| --- | --- |
| Цветные листинги с серым фоном | `\lstset{style=gostcolor}` |
| Ключевые слова полужирным | `\lstset{keywordstyle=\bfseries}` |
| Без номеров строк | `\lstset{numbers=none}` |
| Без рамки | `\lstset{frame=none}` |
| Шрифт кода 10 pt | `\lstset{basicstyle=\ttfamily\fontsize{10}{12}\selectfont}` |
| Без строки «Продолжение листинга N» | `\renewcommand{\suailistingcontinued}{}` |

`\lstset` в преамбуле действует на все листинги. Для одного листинга тот же
ключ пишется в его квадратных скобках:
`\suaicode[Python, numbers=none]{Подпись}`.

## Таблицы

| Что | Строка |
| --- | --- |
| Одинарный интервал в таблицах | `\renewcommand{\suaitablestretch}{1}` |

По умолчанию интервал в таблицах такой же, как в тексте. Настройка
действует на все таблицы: и `\suaitable`, и набранные вручную.

### Таблицы вручную

`\suaitable` не умеет объединять ячейки и задавать ширины. Такая таблица
набирается обычным `tabularx`; подпись, нумерация и `\tabref` работают так
же.

```latex
\begin{table}[H]
  \caption{Состав стенда}\label{tab:stand}
  \begin{tabularx}{\textwidth}{|L{4cm}|Y|R{3cm}|}
    \hline
    Узел & Назначение & Количество \\ \hline
    Сервер & хранение данных & 2 \\ \hline
    \multicolumn{2}{|l|}{Всего узлов} & 2 \\ \hline
  \end{tabularx}
\end{table}
```

Шаблон добавляет типы столбцов:

| Тип | Столбец |
| --- | --- |
| `L{ширина}` | заданной ширины, текст влево |
| `P{ширина}` | заданной ширины, текст по центру |
| `R{ширина}` | заданной ширины, текст вправо |
| `Y` | растягивается на оставшееся место, текст по центру |

Таблица длиннее страницы набирается окружением `xltabular`: оно принимает те
же столбцы и переносится на следующую страницу, как `longtable`.

## Источники через biblatex

Когда источников много, удобнее вести их в файле `.bib` и ссылаться
командой `\cite`: номера и порядок расставятся сами.

В преамбуле:

```latex
\usepackage[backend=biber,style=gost-numeric,language=auto,
            autolang=other,sorting=none]{biblatex}
\addbibresource{sources.bib}
```

В файле `sources.bib` рядом с `main.tex`:

```bibtex
@book{stroustrup,
  author    = {Страуструп, Б.},
  title     = {Язык программирования C++},
  address   = {М.},
  publisher = {Бином},
  year      = {2011},
  pagetotal = {1136},
  langid    = {russian},
}
```

В тексте — ссылка и `\suaisources` без строк под ней:

```latex
Потоки ввода-вывода описаны в~\cite{stroustrup}.

\suaisources

\end{document}
```

Получится «…описаны в [1]» и список, оформленный стилем `gost-numeric`:
«1. Страуструп Б. Язык программирования C++. — М. : Бином, 2011. — 1136 с.»
Сборка командой `suai build` и из VS Code запускает `biber` сама.
