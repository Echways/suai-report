# Если что-то не так

[← К оглавлению](../README.md#документация)

Журнал сборки лежит в `build/main.log`. В VS Code ошибки видны в панели
**Problems** (Ctrl+Shift+M), в терминале их печатает `suai build`.

## Сообщения пакета

| Сообщение | Что случилось и что делать |
| --- | --- |
| `Шрифт 'Times New Roman' не найден, используется 'TeX Gyre Termes'` | Предупреждение: шрифта нет в системе, взят запасной. Отчёт собирается, но титульный лист выверен по Times New Roman — см. [шрифты](install.md#шрифты) |
| `Язык листинга '…' неизвестен, код набран без подсветки` | Предупреждение: проверь название языка — см. [языки](writing.md#языки) |
| `Под \suaicode нет строк с отступом` | Ошибка: код в тексте пишется под командой **с отступом**. Если это код из файла, нужны две пары скобок: `\suaicode[язык]{файл}{Подпись}` |
| `После подписи \suaicode на той же строке ничего не пишется` | Ошибка: код начинается со следующей строки, после подписи может стоять только комментарий |

## Не собирается

**``File `suai-report.sty' not found``.** Шаблон не установлен или установлен
копией, которую потом удалили. Выполни `suai install` (в папке шаблона —
`make install`). Проверка: `kpsewhich suai-report.sty` должна напечатать
путь к файлу.

**Ошибка про XeTeX сразу после `\usepackage{suai-report}`.** Отчёт собирают
`pdflatex` или `lualatex`, а пакет работает только с XeLaTeX. Собирай
командой `suai build` или рецептом из `.vscode/` отчёта; в Overleaf выбери
компилятор XeLaTeX.

**`Undefined control sequence` на команде `\suai…` после обновления.**
Установлена старая копия `suai-report.sty`. Повтори `suai install`.

**``File `scheme' not found``.** Рисунок ищется в папке `images/` и рядом
с `main.tex`. Проверь имя файла и регистр букв.

**`Missing $ inserted` или `Extra alignment tab` в таблице.** В ячейке есть
знак, который LaTeX считает служебным: `_`, `^`, `&`, `#`, `%`. В тексте они
пишутся как `\_`, `\^{}`, `\&`, `\#`, `\%`.

**В Windows `latexmk` не запускается.** MiKTeX не содержит Perl — поставь
[Strawberry Perl](https://strawberryperl.com) и открой новый терминал.

**Команда `suai` не найдена.** Открой новый терминал. Если не помогло,
папки `~/.local/bin` нет в `PATH`: `suai install` пишет об этом в конце.

## Собирается, но выглядит не так

**Абзац после списка стал его пунктом** (или пояснением «где …» под
формулой, или строкой таблицы). Блочная команда читает строки до пустой
строки — оставь её после блока.

**Один пункт превратился в два.** Пункт занимает одну строку исходника.
Если длинная строка разбита вручную, склей её обратно.

**Вместо номера стоит `??`.** Метки с таким именем нет. Проверь имя и то,
что у объекта метка задана: у `\suaitable` и `\suaieq` она в квадратных
скобках, у `\suaiimg` получается из имени файла. Сразу после добавления
объекта `??` пропадают со второй сборки — `latexmk` делает её сам.

**Ссылка ведёт не на тот листинг.** Один файл вставлен дважды, и у обоих
листингов метка `lst:имя-файла`. Дай второму свою:
`\suaicode[C++, part]{stats.cpp}{Подпись}`.

**`firstline` и `lastline` не действуют.** В `\suaicode` эти ключи
не работают. Часть файла выводит `\lstinputlisting` — см.
[параметры листинга](writing.md#параметры-в-квадратных-скобках).

**Таблица разделилась не там.** Черта `|` всегда делит ячейки, кроме черты
внутри формулы. Черта в тексте ячейки пишется `\textbar`.

**Код в листинге без подсветки.** Язык не указан или неизвестен — во втором
случае в журнале есть предупреждение.

**В списке лишние или пропавшие знаки в конце пунктов.** Знаки `;` и `.`
расставляются сами. Чтобы оставить свои, поставь звёздочку: `\suailist*`.

**Текст вылезает на поле.** Чаще всего это длинное «слово» без пробелов
в формуле или в `\url`. Обычный текст и `\texttt{…}` шаблон разрывает сам —
см. [длинные слова](writing.md#длинные-слова-и-переносы).

## Можно не обращать внимания

**`xdvipdfmx:warning: Object @table.1 already defined`.** Появляется при
сборке отчёта с таблицами. На PDF не влияет.

## VS Code

**PDF не обновляется.** Посмотри панель **Problems**: при ошибке сборки
остаётся прошлый PDF.

**Подсказок `\suai…` нет или сборка идёт не тем рецептом.** В отчёте нет
папки `.vscode/` или она устарела — выполни в папке отчёта `suai update`.
Открывать нужно папку отчёта, а не один файл `main.tex`.

**Tab вставляет не то, подсказки дублируются.** Рядом с LaTeX Workshop
стоит второе расширение для LaTeX — удали его, см.
[VS Code](vscode.md#другие-расширения-для-latex).

Не нашлось ответа — напиши в
[issues](https://github.com/Echways/suai-report/issues) и приложи
`build/main.log`.
