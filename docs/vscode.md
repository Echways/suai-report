# VS Code

[← К оглавлению](../README.md#документация)

`suai new` кладёт в отчёт папку `.vscode/` с настройками для расширения
[LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop).
При первом открытии папки VS Code сам предложит его установить.

## Предпросмотр

Открой `main.tex` и нажми **Ctrl+Alt+V** — справа появится PDF.

- Файл сохраняется сам через секунду после правки, отчёт пересобирается при
  каждом сохранении, PDF справа обновляется.
- **Ctrl+щелчок** по месту в PDF переводит курсор на эту строку исходника.
  **Ctrl+Alt+J** показывает в PDF место, где стоит курсор.
- Ошибки сборки видны в панели **Problems** (Ctrl+Shift+M). Всплывающих
  окон нет.
- Служебные файлы лежат в `build/`, в списке файлов эта папка скрыта.
  Готовый PDF для сдачи — рядом с `main.tex`, имя собрано из двух папок:
  `Databases/lab-3/` → `Databases-lab-3.pdf`.

Сборка та же, что у [`suai build`](cli.md#сборка): XeLaTeX через `latexmk`,
при необходимости с `biber`.

## Подсказки команд

После `\` LaTeX Workshop подсказывает команды шаблона с аргументами
и описанием: `\suaita` → `\suaitable[метка]{Название}`.

- Подсказку принимает **Tab**. **Enter** всегда даёт новую строку.
- Внутри `\suaisetup{…}` подсказываются ключи титульного листа.
- Внутри `\figref{…}`, `\tabref{…}`, `\lstref{…}` и `\formref{…}`
  подсказываются метки из последней сборки: `fig:scheme`, `tab:reading`,
  `eq:mean`, `lst:build`. Новая метка появляется в списке через пару секунд
  после сохранения.

## Сниппеты

Шаблоны «ссылка в тексте + объект» набираются словом и **Tab**: на каждый
рисунок, таблицу, формулу и листинг в тексте должна быть ссылка, и сниппет
ставит её сразу.

| Слово | Что вставляет |
| --- | --- |
| `img`, `рис` | «Схема приведена на рисунке …» и `\suaiimg` |
| `tab`, `табл` | «Данные приведены в таблице …» и `\suaitable` со строками |
| `eq`, `форм` | «Значение рассчитывается по формуле (…)» и `\suaieq` с пояснениями |
| `lst`, `лист` | «Код приведён в листинге …» и `\suaicode` с кодом под ней |
| `code`, `код` | то же для `\suaicode` из файла |

Например, `tab` и Tab дают:

```latex
Данные приведены в~\tabref{name}.

\suaitable[name]{Название таблицы}
Параметр  | Значение
Процессор | 8 ядер
Память    | 16 ГБ
```

Первая остановка — метка (у рисунка и кода из файла — имя файла): ссылка
над объектом меняется вместе с ней. Дальше Tab переходит по подписи
и ячейкам. В сниппетах листингов язык выбирается из списка.

## Обновление настроек

Настройки в `.vscode/` — копия файлов из `src/vscode/` шаблона. После
`git pull` в папке шаблона их обновляет команда, запущенная в папке отчёта:

```bash
suai update
```

Правки, сделанные прямо в `.vscode/` отчёта, при этом затираются.
